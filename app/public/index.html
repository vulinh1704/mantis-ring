Ring is a coding agent that fixes UI bugs in a web project: text that overflows on a phone, layouts that break in another language, colours that disappear in dark mode. It works on a copy of the project inside a throwaway gVisor sandbox on Vultr, with no secrets and no way out except a proxy that allows only npm and GitHub. After each batch of edits, Mantis, an open-source checker that uses no AI, measures every route, screen size, colour scheme and language in the task again and compares them with the starting point. A change that only hides a problem is reported as a cover-up and rolled back, and so is one that makes a page stop loading. Each run ends with a receipt that shows what was fixed, what is new, which models worked on it and what they cost. A person approves before the patch is handed out as a file; the demo never applies it anywhere.
